Out-of-the-Box FortiGate Lab

From the box to google.com: console, GUI, the four basics, route, policy, license, NAT, test.

Getting through the gate · the order never changes

Challenge tasks

Work out each task on your own, in the console (CLI) or the GUI. The phase bar and the gate show your progress.

Task 1. Plug in the console cable
Connect the laptop to the FortiGate with no network at all.
Why is the console the first way in?
Hint
Click Plug in the console cable above the gate. The console needs no network: laptop USB › RJ-45 to USB cable › CONSOLE port.
Task 2. First login on the console
Log in with the factory account, set a strong password, and find the GUI address.
What address does port1 have from the factory?
Hint
In the console: type admin, then just press Enter at Password (it's blank). Set a new strong password twice. Find port1's address with: get system interface ...
Task 3. Open the GUI from the laptop
Reach the FortiGate GUI from the laptop's browser.
Why does the browser warn about the certificate?
Hint
Click Plug the laptop into port1, open the laptop's Browser, go to https://192.168.1.99 › Advanced › Proceed, then log in as admin.
Task 4. The four basics
Name it FGT-HQ, set Manila time from NTP, close idle sessions after 10 minutes, then back it up.
Why is the backup last?
Hint
System › Settings (Host name, Time Zone, NTP, Idle timeout), then admin ▾ › Configuration › Backup. Or: config system global › set hostname ... › set timezone ... › set admintimeout ... › end, then config system ntp › set ntpsync ... › end, then execute backup config flash ...
Task 5. Give port4 its internet address
Give port4 the ISP address 203.0.113.2/24. Allow only ping on it.
Why only PING on the internet door?
Hint
Network › Interfaces › Edit port4 (Manual, IP/Netmask, PING only). Or: config system interface › edit port4 › set ip ... › set allowaccess ... › end
Task 6. Route to the internet
Add a default route to the ISP gateway 203.0.113.1 through port4.
The FortiGate can ping 8.8.8.8. Why can't the laptop browse yet?
Hint
Network › Static Routes › Create New (Destination 0.0.0.0/0). Or: config router static › edit 0 › set gateway ... › set device ... › end
Task 7. The catch-all policy
Create one rule that lets the office (port1) out to the internet (port4). Leave NAT off for now.
The rule says accept. Why does google.com still fail?
Hint
Policy & Objects › Firewall Policy › Create New (In, Out, all, ALL, accept, NAT off). Or: config firewall policy › edit 0 › set srcintf ... › set dstintf ... › set srcaddr all › set dstaddr all › set service ALL › set schedule always › set action ... › end
Task 8. Put in the FortiGuard license
Register the FortiGate with the code on the license card, then update the definitions.
What changed on the FortiGuard page?
Hint
GUI only: System › FortiGuard › Enter Registration Code (the code is in What's in the box), then Update Licenses & Definitions Now. Check it with: get system status
Task 9. Turn on NAT
Make the rule swap the laptop's address for the firewall's.
What address will the internet see now?
Hint
Policy & Objects › Firewall Policy › edit your rule › NAT on. Or: config firewall policy › edit 1 › set nat ... › end
Task 10. Test from the laptop: google.com
Open google.com from the laptop and explain every box on the gate.
Which three checks did the packet pass, and in what order?
Hint
In the laptop's Browser type google.com. Then read the gate, or check: get router info routing-table all and show firewall policy
