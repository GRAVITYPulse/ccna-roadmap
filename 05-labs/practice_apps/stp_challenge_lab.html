STP Election Rules IEEE 802.1D

1. Root Bridge: Lowest Bridge ID (Priority, then MAC).

2. Root Port (RP): Lowest path cost to Root.

3. Designated Port (DP): Lowest cost segment port.

4. Alternate Port (AP): Blocking state (prevents loops).

Tie-Breakers (in order):

  1. Lowest Sender Bridge ID
  2. Lowest Sender Port ID (e.g. Fa0/1 > Fa0/2)
